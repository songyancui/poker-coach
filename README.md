# 德州教练 · Poker Coach

边打边学的德州扑克训练工具：和 5 个不同风格的电脑对手打 6 人桌，每次轮到你时，教练会算给你看——胜率怎么来的、赔率够不够、该怎么打、为什么。打完一手还有完整复盘。

- 纯前端，**一个 HTML 文件**就是全部游戏，离线可玩
- 可以打包成 **Android App**（Capacitor）
- 可选接入 **DeepSeek**，随时向 AI 教练提问

> 仅用于学习和娱乐，不涉及任何真钱。

## 功能

**牌局**
- 6 人桌无限注德州，盲注 1/2，每人 100BB
- 5 个电脑对手，名字就是风格：紧弱、松弱（跟注站）、紧凶、松凶、平衡——学会针对不同风格调整

**教练（每次轮到你时）**
- 建议动作 + 理由，以及各选项（弃牌 / 跟注 / 不同大小的下注）的期望值对比
- **概率手算过程**：底池赔率的两种算法、补牌概率（47 张未知牌、“1 − 都不中”）、和口算法的误差对比
- **胜率怎么算**：每个对手的范围（例如“前 11%：88+ · ATs+ · KQo”）及其来源，随机模拟 3500 局的结果，每个对手各自的胜率
- 起手牌排名、位置、牌型、outs、SPR、对手视角需要的胜率
- 每次提示 1–3 条好记的口诀，例如「4-2 法则」「超八减超」「半池四分一，满池三分一」
- 自测模式：先自己猜胜率、做决定，再看点评

**评分与复盘**
- 每步按“损失了多少期望值”打分（✅ / 🟡 / ❌）
- 整手时间线、对手真实底牌下你的真实胜率、“输了但打得对 / 赢了但有失误”的结果与决策分离评价
- 保存最近 60 手，可按“有失误 / 输钱的”筛选

**学习**
- 速算练习：底池赔率、outs、赔率换算、翻前概率、搏三条、诈唬弃牌率
- 概率速记表、实战口诀、各位置开池范围表、知识要点
- 长期统计：VPIP、PFR、bb/100、按位置和街道的得分、最常见的问题

## 快速开始

### 网页版（电脑）

直接用浏览器打开 `index.html` 即可打牌。

需要“问教练”时，用自带的本地服务打开：

```bash
python3 server.py
```

然后访问 http://localhost:8765/ 。DeepSeek 密钥二选一：

- 在页面右上角 ⚙︎ 设置里填写（保存在浏览器本地）
- 或在 `server.py` 同目录新建 `deepseek_key.txt`（只写一行密钥；已在 `.gitignore` 中，不会被提交）

### Android App

从 [Releases](../../releases) 下载 APK 安装（调试版，需允许“安装未知来源应用”）。

自己打包需要 Node.js、JDK 21 和 Android SDK：

```bash
./build-apk.sh
```

默认按 Homebrew 的安装路径查找 JDK 和 SDK，其他路径可以用环境变量指定：

```bash
JAVA_HOME=/path/to/jdk21 ANDROID_HOME=/path/to/android-sdk ./build-apk.sh
```

手机通过 USB 连接并开启 USB 调试时，脚本会自动安装到手机。

## 问教练（DeepSeek）

- 在 [platform.deepseek.com](https://platform.deepseek.com) 创建 API 密钥，填到 App 的设置里，点“测试连接”确认
- 模型可选：Flash 快速回答（默认）、Flash 深度思考、V4 Pro
- 提问时会自动附上当前牌局、教练分析和胜率明细
- 密钥只保存在你的设备上，请求从设备直接发往 `api.deepseek.com`

## 计算方法说明

- **起手牌排名**：Chen 公式排序，“前 X%”表示从最强往下数 X% 的组合
- **对手范围**：按风格的入池率 / 加注率 × 位置系数估计，随动作收窄；翻牌后主动下注的对手，未击中公共牌的牌只按其诈唬倾向保留一部分
- **胜率**：蒙特卡洛模拟（翻前 2500 局、翻后 3500 局），在 Web Worker 中计算
- **期望值**：简化模型，只算到本街；被跟注时按更强的跟注范围折算胜率，弃牌率按对手风格和下注大小估计

这些都是近似值，适合练习思路，不是 GTO 解算器的精确解。
